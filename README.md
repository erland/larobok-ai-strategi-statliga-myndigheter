# AI-strategi för statliga myndigheter

**Undertitel:** Hur verksamhetsstrateger och verksamhetsarkitekter leder AI-arbetet från idé till verksamhetsförmåga  
**Författare:** Erland Lindmark  
**Språk:** Svenska  
**Version:** 0.1  
**Datum:** 2026-06-03

Detta är ett bokprojekt för en svensk lärobok/handbok om AI-strategi, inriktning och införande i statlig myndighet.

## Projektstruktur

- `chapters/` innehåller manus.
- `docs/` innehåller bokspecifikation, kapitelplan, projektstatus, canon och exportmetadata.
- `assets/cover/` är avsedd för omslagsbild.
- `assets/image-prompts/` innehåller promptar för omslag.
- `scripts/` innehåller lokal exportpipeline.
- `styles/` innehåller CSS för EPUB/PDF.
- `exports/` är målplats för genererade exportfiler.

## Nästa steg

1. Granska bokspecifikation och kapitelplan.
2. Skapa eller godkänn omslaget.
3. Skriv kapitel 1.
4. Uppdatera projektstatus och exportmetadata när nya kapitel läggs till.
